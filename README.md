# Open Source Ricochet Arena - Only Confirmed to Work on Windows and Some Linux Devices
<br>

## Description
This Project is based off the Valve made game Ricochet from 2000.
Its an arcade disc shooter that uses launch pads to jump around
with power ups and other things. Our version does not include these
power ups and launch pads as we wanted to go for a fun arcade two
dimensional platform fighter.
